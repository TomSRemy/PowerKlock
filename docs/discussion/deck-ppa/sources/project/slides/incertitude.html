Quantifier l’incertitude

Trois sources d’incertitude, une seule fourchette aujourd’hui

1 · La météo

Bien mesurée : années météo simulées ou tirées

Donne la dispersion d’une année à l’autre

2 · Le modèle

Mesurée par les erreurs du rejeu, élargies quand le rejeu est court (loi de Student)

A triplé depuis 2023 : la fourchette doit suivre

3 · Le marché et les règles

Niveau du forward, crise, nouvelles règles d’arrêt, stockage

Pas dans la fourchette : traité par les scénarios de stress

Méthode proposée : fourchette = météo + erreurs mensuelles récentes du rejeu (années récentes plus lourdes), vérifiée par son taux de réussite ; le stress reste à part. Le P75 est un choix de prudence commerciale, pas une prévision.

Bande de la moyenne : réalisé dedans 2 années sur 3 en solaire et en éolien · méthode choisie par le protocole : éolien 0 sur 3

L’incertitude a trois sources : la météo, qu’on mesure bien ; le modèle, qu’on mesure par le rejeu ; et le marché et les règles, qui relèvent des scénarios de stress. Aujourd’hui la fourchette sous-estime l’erreur de modèle : le réalisé n’y est que deux années sur trois. Et le P75 est une décision de prudence, pas une prévision.
