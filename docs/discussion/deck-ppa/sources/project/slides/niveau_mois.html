Ce qu’on a trouvé

Le cadre commun (diapo 11) dit : niveau du mois × forme du mois. Le reste de l’outil le fait : pricer court terme, éventail de capture, page du matin.

Dans le pricer long terme, forme forward et simulation météo lisent les mois cotés ; tendance de capacité et décote P74 prenaient le Cal plat ; le modèle européen le Cal × la forme historique.

Le marché cote cet hiver une prime d’hiver 2027 très forte (janvier 210 €, mai 64 €) : l’éolien, qui produit l’hiver, vaut 12 % de plus que le Cal.

Mois cotés : SEFE, dernières clôtures (mois, sinon trimestre, saison, puis Cal découpé par l’historique) · data/history/fr_forward_monthly.json · scripts/ppa_forward_shape_test.py
