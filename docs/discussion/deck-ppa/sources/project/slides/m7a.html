Simulation météo : le Monte Carlo du pricer

prixh ÷ moyenne = table[ groupe, demande − solaire − éolien − nucléaire disponible (GW) ]

Les étapes

Années météo simulées : production solaire et éolienne heure par heure

Demande et nucléaire disponible tirés dans l’année précédente, même mois, même type de jour

Prix ÷ moyenne lu dans une table : demande nette France (par GW) × 6 groupes, apprise sur les 2 dernières années

Avec les vrais chiffres

France seule, pas de voisins

Table = moyenne des prix par case : une moyenne passe rarement sous zéro

D’où presque pas d’heures ≤ 0 € simulées

Paramètres calculés sur 2016–2025 hors 2022, convention curtailment · ppa_lab.json · ppa_walkforward.json · scripts/ppa_backtest_detail.py

La simulation météo est le Monte Carlo qui existait déjà. Il simule bien la météo et la production. Son modèle de prix est simple : une table de prix moyens selon la demande nette française, apprise sur deux ans. Comme on lit une moyenne, on ne tombe presque jamais sous zéro.
