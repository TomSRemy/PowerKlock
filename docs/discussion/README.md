# Discussion — tools and pricing

A place where Tom and the Claude sessions working on PowerKlock talk through the tools and the pricing
methods, before anything reaches the site. This branch (`discussion`) is never published: it holds no code.

## How to write here
- One file per subject in this folder. Add to the end of a file, never rewrite someone else's entry.
- Each entry starts with a line `### YYYY-MM-DD HH:MM · who` (who = Tom, or the session name, e.g. `powerklock-78`,
  `bridge-cse`), then short paragraphs. Numbers with their unit and source.
- A question for Tom ends with **→ Tom**; a decision taken by Tom is written **Decision:** and copied into
  `decisions.md` with its date.
- Tom can write straight on GitHub (pencil icon on the file, "Commit directly to the discussion branch").
- No client names, no client figures, no secrets: the repository is public.

## Subjects
- [pricer.md](pricer.md) — the PPA pricer: which price the site publishes, the methods, the European model, tests
- [tools.md](tools.md) — how the tools read and work day to day (PPA, BOA, forecast, carbon, comparator, converter)
- [roles.md](roles.md) — who does what, how a change reaches the site
- [site.md](site.md) — the whole site: pages, figures, data, languages, phones
- [decisions.md](decisions.md) — decisions taken, dated
